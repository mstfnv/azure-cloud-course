# Azure Cloud Engineering Project
Secure, scalable web app deployed on Azure using Bicep (IaC) and 
GitHub Actions (CI/CD). Includes VNet/NSG networking, App Service, 
and Azure SQL Database.

## Stack
Bicep · GitHub Actions · Azure App Service · Azure SQL · VNet/NSG

## Deploy
az deployment group create --resource-group <rg> --template-file main.bicep
